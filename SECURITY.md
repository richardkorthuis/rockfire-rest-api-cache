# Security policy

## Supported versions

Security fixes are released for the latest version of the plugin only. Please update before reporting.

## Reporting a vulnerability

Please do not report security issues in a public issue or pull request.

Report them through the
[Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/3b6565d9-6316-455d-8034-ac732df8b164).
The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
Include the affected version, the steps to reproduce and the impact you expect.

Once a fix is released, the issue is disclosed in the changelog, and reporters are credited unless they prefer
otherwise.
