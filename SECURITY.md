# Security policy

## Supported versions

Security fixes are released for the latest version of the plugin only. Please update before reporting.

## Reporting a vulnerability

Please do not report security issues in a public issue or pull request.

Report them privately through
[GitHub's private vulnerability reporting](https://github.com/richardkorthuis/rockfire-rest-api-cache/security/advisories/new).
Include the affected version, the steps to reproduce and the impact you expect.

You will get a response within a few working days. Once a fix is released, the issue is disclosed in the changelog,
and reporters are credited unless they prefer otherwise.
